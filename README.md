# VibeCode Hub

Современный дашборд для Claude Code, ChatGPT-промптов, скиллов, плагинов и open-source агентов.

## Открыть сайт
После включения GitHub Pages: https://hursaalo.github.io/vibecode-hub/

## Что внутри
- 10 читерских кодов ChatGPT (мультивыбор + сборщик промпта)
- 5 мощных скиллов для Claude Code
- 24 плагина / навыки / MCP (с заменами под РФ)
- Must-have: **OmniRoute**, Claude Mem, Headroom, Claude Code Setup, Task Observer
- Open-source: DeepSeek Harness (`npx @deepseek-ai/dsh web`), файл-запретов Karpathy-style
- Интерактивный чек-лист легального сайта

## Ключевые ссылки из роликов
- OmniRoute: https://github.com/diegosouzapw/OmniRoute
- Инструкция Claude Code + OmniRoute: https://github.com/diegosouzapw/OmniRoute/wiki/Claude-Code-Configuration
- DeepSeek Harness: https://github.com/deepseek-ai/deepseek-harness
- Запуск: `npx @deepseek-ai/dsh web` → http://127.0.0.1:3080
- Официальные плагины Anthropic: https://github.com/anthropics/claude-plugins-official

## Как включить GitHub Pages
1. Settings → Pages
2. Source: Deploy from a branch
3. Branch: main, folder: / (root)
4. Save

Полный `index.html` обновляется в следующем коммите.
