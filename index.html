Все нюансы и ошибки

❌ git : Имя "git" не распознано

Git не установлен или не в PATH.

Вариант А — поставить Git:

  1. Скачай git-scm.com/download/win
  2. Установи (можно всё по умолчанию)
  3. Закрой и заново открой PowerShell
  4. Проверь: git --version

Вариант Б — без Git (ZIP):

  1. Открой github.com/diegosouzapw/OmniRoute
  2. Code → Download ZIP
  3. Распакуй → в PowerShell: cd путь\к\OmniRoute
⚠️ npm warn install-scripts

Claude Code поставился, но postinstall заблокирован. Выполни:

npm install -g --allow-scripts=@anthropic-ai/claude-code

Проверка: claude --version

claude не находится после установки

Закрой PowerShell полностью и открой новый. npm добавляет путь в PATH только для новых сессий.
